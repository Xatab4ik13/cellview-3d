# План

Сделать вместо тяжёлого объёмного виджета лёгкую карту склада сверху.

## Что изменю
- Убрать 3D-виджет с главной страницы.
- Оставить публичный API статусов ячеек, который отдаёт только номер и статус.
- Сделать лёгкую 2D-карту: номера ячеек, цвета статусов, выбор ячейки.
- При выборе ячейки показывать стрелочный маршрут от входа до выбранной ячейки.

## Технически
- Извлечь из текущего файла плана координаты дверей/ячеек и сохранить их как лёгкие данные для SVG/Canvas.
- Новый виджет не будет загружать `three.js` и `.glb` на главной странице.
- Если точных коридоров в данных не окажется, маршрут будет строиться по ближайшей безопасной линии прохода к двери ячейки.

## Что не меняю
- Каталог, CRM, оплаты и данные ячеек не трогаю.
- 3D-файлы можно оставить в `public/plan` как архивный вариант, но главная их использовать не будет.
